## /develop - 기능 구현 커맨드

사용자의 요구사항을 분석하고, 서브에이전트를 활용하여 클린 아키텍처 기반으로 기능을 구현합니다.

### 실행 흐름

1. **요구사항 분석**: 사용자의 입력(`$ARGUMENTS`)을 분석하여 구현 범위를 파악합니다.

2. **Skills 참조**: 구현 전 반드시 `.claude/skills/` 디렉토리의 모든 스킬 파일을 읽고, 해당 규칙을 코드 작성 시 적용합니다.

3. **구현 계획 수립**: `requirement-planner` 에이전트를 사용하여 요구사항이 모호하거나 범위가 넓은 경우 구체적인 구현 계획을 먼저 수립합니다.

4. **코드 구현**: `code-implementer` 에이전트를 사용하여 실제 코드를 구현합니다.

5. **빌드 검증**: 구현 완료 후 `./gradlew compileKotlin`으로 빌드가 정상적으로 되는지 확인합니다.

### 지시사항

- `$ARGUMENTS`가 비어있으면 사용자에게 구현할 기능을 물어보세요.
- 항상 `.claude/skills/` 디렉토리의 모든 파일을 읽고 규칙을 따르세요.
- 요구사항이 명확하고 단순하면 `requirement-planner`를 건너뛰고 바로 `code-implementer`로 구현하세요.
- 요구사항이 모호하거나 여러 파일에 걸친 작업이면 반드시 `requirement-planner`로 계획을 먼저 세우세요.
- 구현 후 빌드 검증까지 완료해야 작업이 끝난 것입니다.
